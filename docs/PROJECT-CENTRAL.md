# Central do Projeto WSL / Codex

Atualizado em 2026-09-19.

Este repositório centraliza o trabalho do projeto WSL focado em transformar o ambiente local em uma estação de desenvolvimento profissional orientada por Codex.

## Frentes consolidadas
1. WSL limpo e reproduzível para desenvolvimento.
2. Codex CLI nativo com AGENTS.md, especialistas, skills, MCP, hooks, memória e diagnostics determinísticos.
3. Economia de tokens com RTK, Atlas, SigMap, Serena, mcp2cli, Headroom e Tokview.
4. Especialistas para Python, Django, PHP, React, MySQL, PostgreSQL, Redis e orquestração full-stack.
5. Especialista de infraestrutura para Linux, Docker, proxy, bancos, observabilidade, backup e troubleshooting.

## Convenção
- archive/: pesquisa e artefatos históricos.
- scripts/: automação executável.
- specialists/: pacote de agentes/skills.
- docs/: decisões e instruções humanas.
- config/: exemplos seguros sem segredos.

Este repo deve ser tratado como a fonte canônica do harness.
